# Instituto Balbino Fé com Obras

Site institucional moderno e responsivo para o Instituto Balbino Fé com Obras.

## 🚀 Características

- **Design Moderno**: Interface limpa e profissional
- **Totalmente Responsivo**: Funciona perfeitamente em todos os dispositivos
- **Menu Mobile**: Menu hambúrguer funcional para dispositivos móveis
- **Performance Otimizada**: Carregamento rápido e suave
- **Acessibilidade**: Código semântico e acessível

## 📁 Estrutura do Projeto

```
institutobalbino/
├── index.html              # Página inicial
├── sobre.html              # Página sobre nós
├── galeria.html            # Galeria de fotos e vídeos
├── contato.html            # Página de contato
├── assets/
│   ├── css/
│   │   └── style.css       # Estilos principais
│   ├── js/
│   │   └── main.js         # JavaScript principal
│   ├── images/             # Imagens e vídeos
│   └── fonts/              # Fontes personalizadas
└── README.md               # Este arquivo
```

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estrutura semântica
- **CSS3**: Estilos modernos com variáveis CSS
- **JavaScript ES6+**: Funcionalidades interativas
- **Google Fonts**: Tipografia Inter
- **CSS Grid & Flexbox**: Layout responsivo

## 🎨 Design System

### Cores
- **Primária**: #2c5530 (Verde escuro)
- **Secundária**: #4caf5c (Verde)
- **Accent**: #45a049 (Verde médio)
- **Texto**: #2c3e50 (Azul escuro)
- **Cinza**: #7f8c8d (Cinza médio)

### Tipografia
- **Fonte Principal**: Inter (Google Fonts)
- **Pesos**: 300, 400, 500, 600, 700

## 📱 Responsividade

- **Desktop**: Layout completo com todas as funcionalidades
- **Tablet**: Ajustes de espaçamento e tamanhos
- **Mobile**: Menu hambúrguer e layout otimizado
- **Breakpoints**: 768px (mobile), 480px (mobile pequeno)

## ⚡ Funcionalidades

### Menu de Navegação
- Menu fixo com efeito de transparência
- Menu hambúrguer animado para mobile
- Fechamento automático ao clicar em links
- Indicador visual da página ativa


### Galeria
- Grid responsivo para imagens
- Efeitos hover suaves
- Vídeos integrados
- Layout adaptativo

### Animações
- Fade-in ao scroll
- Hover effects nos cards
- Transições suaves
- Animações de entrada
